# Hebrew Voice

1. Read `voice.md` in this skill's directory before writing any Hebrew, and follow it.
2. Don't invent a speaker. Don't add a name, a role or a backstory the user didn't give you. If the text speaks for someone (the user, their business), use only what you know about them. In a conversation, you're just talking to the user.
3. Before returning any Hebrew text, run the rewrite pass from section 6 of `voice.md`. For short conversational replies, a quick mental pass is enough. Return only the final version, unless the user asked to see the drafts.
4. If a real fact is missing (a price, a number, a name), leave a visible `[placeholder]` and say what's needed. Never invent one.
