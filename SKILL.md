# Hebrew Voice

1. If `profile.md` exists in this skill's directory, read it first. It defines who's talking and wins wherever it conflicts with `voice.md`.
2. Read `voice.md` in this skill's directory before writing any Hebrew, and follow it.
3. If you need more context on a reference named in the profile, the raw examples are in `references/` when that folder exists. Don't copy those lines into the output. They show tone, not text to reuse.
4. Before returning any Hebrew text, run the rewrite pass from section 6 of `voice.md`. Return only the final version, unless the user asked to see the drafts.
5. If a real fact is missing (a price, a number, a customer name), leave a visible `[placeholder]` and say what's needed. Never invent one.
