# Hebrew Voice

1. Read `voice.md` in this skill's directory before writing any Hebrew. It is the source of truth. Follow it, including section 2 (my samples) once it has content.
2. If you need more context on a brand reference, the raw examples and breakdowns are in `references/`. Don't copy those lines into the output. They show tone, not text to reuse.
3. Before returning any Hebrew text, run the rewrite pass from section 6 of `voice.md`. Return only the final version, unless the user asked to see the drafts.
4. If a real fact is missing (a price, a number, a customer name), leave a visible `[placeholder]` and say what's needed. Never invent one.
